# Dockify S0: kontras token per opsi (WCAG 2.x)

Dihitung oleh `gen.mjs` (luminans relatif WCAG). Minimum: teks 4.5:1, batas kontrol dan grafis 3:1. Status: semua lolos.

Ringkasan: opsi 1 38/38 lolos · opsi 2 38/38 lolos · opsi 3 38/38 lolos (12 pasangan wajib + 7 tambahan per tema).

Lencana Dockify: running/online = ok (`ok-bg` + `ok-text`); pending/initializing/deploying = warn (`warn-bg` + `warn-text`); stopped/draft = netral (`sunk` + `ink2`, garis `line`); error/failed/offline = danger (`danger-bg` + `danger-text`).
